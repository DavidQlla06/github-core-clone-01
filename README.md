A standalone GitHub-compatible git forge in a single Node process: it serves git smart HTTP (protocol v0 and v2, shallow clones, receive-pack with fast-forward checks), the REST v3 API, GraphQL v4 and MCP tools, all backed by its own in-memory store — no UI, no dependencies, no git binary.

## Run it

```sh
node main.ts
```
